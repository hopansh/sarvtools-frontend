# SarvTools 🇮🇳  

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)  

**A zero-server, privacy-focused toolbox**  

## Features  
- **100% client-side processing** (no data leaks).  
- **50+ tools** across categories.  
- **Open-source** with easy contributions.  

## Quick Start  
1. Clone the repo:  
   ```bash  
   git clone https://github.com/hopansh/sarvtools.git  
    ```

2. Install dependencies:
    ```bash
    npm install  
    ```
3. Run locally:
    ```bash
    npm run start
    ```
## Contribute
Add a new tool: Fork → Create a folder in /src/tools → Submit PR!
